# KnightPath — Google Stitch Prompt Pack (v2 — Light "Daylight Kingdom")

**How to use:** Stitch doesn't reliably remember style between generations, so CONSISTENCY comes from pasting the same STYLE BLOCK at the start of every screen prompt. Copy the block, then the screen prompt below it, as one message. Generate screens in the order listed (start with Home — it sets the tone; regenerate others to match it if Stitch drifts).

**Design direction:** Duolingo's bright game energy + a royal chess identity. They own green; we own **royal purple + gold** (chess = royalty, crowns). Board stays classic tournament green for proven readability.

---

## 🎨 STYLE BLOCK (paste at the top of EVERY prompt)

```
Design a bright, playful, premium mobile game UI for an iOS chess game called "KnightPath". Style like Duolingo's game energy but with a royal chess identity — NOT a SaaS app, NOT corporate flat design, never childish-cluttered.

Colors: clean white #FFFFFF background, soft lavender-tinted sections #F7F4FF, cards outlined with 2px light borders #E5E0F0 and 16px corner radius. Brand color royal purple #7C3AED for CTAs, selections, active states. Gold #F5A623 for coins, stars, crowns and rewards. Green #58CC02 for success/wins, red #FF4B4B for danger/check, orange #FF9600 for streak flames. Text dark plum #3C3654, secondary text #8B84A3.

Chess board: classic tournament green dark squares #779952 and cream light squares #EDEED1, elegant stylized 2.5D chess pieces with soft drop shadows.

Buttons: chunky Duolingo-style 3D buttons — solid purple fill with a darker purple #5B21B6 bottom edge (4px) so they look physically pressable. Secondary buttons white with purple border. Big rounded bold typography (SF Rounded style), chunky friendly numerals for coins and XP.

Overall: bright, celebratory, game-like, playful illustrated characters, generous white space, colorful reward moments, premium polish. iPhone 15 Pro portrait frame.
```

## Consistency tips for Stitch

1. **Generate Home first**, then reference it: if a later screen drifts, add "match the exact visual style, colors and component treatment of the previous Home screen" to the prompt.
2. **If Stitch goes flat/SaaS:** add "more game-like: chunky 3D buttons with darker bottom edges, playful illustrated elements, celebratory feel — this is a game, not a dashboard app."
3. **If it goes childish/cluttered:** add "more premium and polished — generous white space, refined details, elegant chess pieces."
4. **If purple drifts to blue:** re-state "brand color is royal purple #7C3AED, never blue."
5. **Bot portraits will vary** — Stitch is for layout/UI. Treat its character art as placeholders; we'll generate the real 9-bot set separately with a locked style reference.
6. **Iterate one element at a time** ("make the CTA chunkier", "more white space around the board") rather than regenerating whole screens.
